1. Install uv (pick one):

powershell
# Official installer (recommended)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
powershell
# Or via winget
winget install --id=astral-sh.uv -e
powershell
# Or, if you already have Python + pip
pip install uv

2. Close and reopen your terminal. The installer adds uv to your PATH, but already-open windows won't pick up the change. If you're in VS Code, restart VS Code entirely, not just the terminal tab.

3. Check it works:

powershell
uv --version

Then run uv init . again.

If it's still "not recognized" after reopening, the official installer puts uv in %USERPROFILE%\.local\bin. You can add it for the current session with:

powershell
$env:Path = "$env:USERPROFILE\.local\bin;$env:Path"
